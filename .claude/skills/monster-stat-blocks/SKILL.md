# Monster stat blocks

Monsters are `ExtendedCombatantData` subclasses (`Model/Creatures/Combatants.py`) whose traits and actions are `MonsterAbility` entries (`Model/Creatures/MonsterAbilities.py`).

## Where monsters live, and what you may edit

- `Combat/Monsters/CR_<tier>/`: fractional CRs (1/8, 1/4, 1/2) go in `CR_0`; integer CRs go in `CR_<that integer>`.
- **`monsters_homebrew.py`**: hand-written homebrew monsters. Edit freely. If the tier has no such file yet, create it. No `__all__`, and don't touch the tier's `__init__.py` (it only re-exports `monsters.py`). Homebrew monsters are imported directly: `from Combat.Monsters.CR_7.monsters_homebrew import TheCrownWithoutAKing`.
- **`monsters.py` with no "hand-edited" header**: generated by `Combat/Tools/generate_monsters.py` from raw JSON. **Don't edit it**; the next regeneration silently discards your change. Ask first. If the user agrees, add a header comment like CR_10's (which classes were touched, and that regeneration overwrites them) before any other edit.
- **`monsters.py` marked hand-edited** (e.g. CR_0, CR_10, CR_17; see their top-of-file comment): safe to edit.
- Never read a whole `monsters.py`; they run to thousands of lines. Grep for the class name or the `combatant_type=` string, then read with `offset`/`limit` around that class only.

## House rules for homebrew monsters

- At most **4 `MonsterAbility` entries in total** (traits + actions + bonus actions + reactions; Multiattack counts), preferably at least one trait. Fold riders into existing lines (e.g. a smite as a trait, several spells as one "X Magic" action).
- Every new or edited homebrew monster is balanced with the `balance-monster` skill before it's done.

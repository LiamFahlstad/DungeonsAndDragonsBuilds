# Complex features to review

Written 2026-10-11. This is a list of Feature implementations that compute numbers, change stats, or build stat blocks, so they deserve a careful check against the rules text. It came from a quick read-only survey by six haiku agents (one per slice of `CharacterContent/Features/`), merged and deduplicated by hand. The surveyors did not verify correctness, so their "-" in the Notes column means "nothing noticed", not "checked". Code links point at the class or function definition.

**Totals:** 4 confirmed bugs, 33 high priority, 140 medium priority.

**Status column (✓):** ☐ not reviewed · ✅ reviewed, looks good · 🔧 reviewed and fixed (what was fixed is in the Notes column) · ❓ reviewed, needs your input (usually a missing source text). Reviews were done against the source text and the rendered sheet.

## How to review

For each row: read the source text, read the code, then render a build that uses it (see below) and read the actual sheet output. The two bugs found so far were only visible in the rendered output:

- **Silent stat-block data loss.** `format_creature_stat_block` reads `ability_scores` / `saving_throws` by `Ability.short_name` (`"STR"`, `"DEX"`, ...). Any other key spelling silently renders as 10 (+0) and drops saves. Found in the Drake Companion, the three Primal Companions and the Wildfire Spirit, all fixed. Since 2026-10-11 creatures reject any other key on creation (`_normalize_ability_keyed_dict` in `Model/Creatures/Combatants.py`), and stat blocks use `Ability` enum keys (`{Ability.STRENGTH: 14, ...}`), so this can't recur silently.
- **Rule described but not applied.** Circle Forms said "AC = 13 + WIS" in its text but the wild shape cards kept the beast's AC. Watch for features whose description promises a number that the sheet never shows.

Other patterns the survey flagged repeatedly:

- Uses that scale with proficiency bonus or an ability modifier (`levels_gained(proficiency_bonus, ...)`, `max(1, mod)`): check the minimum of 1 and the PB steps at levels 5/9/13/17.
- Damage dice that step up at specific levels: check the exact thresholds against the source.
- `extends=` features (Improved Defender, Perfected Armor, Explosive Cannon): check the upgrade shows on the parent's card regardless of grant order.
- `has_feature` counts extensions (since 2026-10-12). Before that it only saw plain grants, so a parent card that asked `has_feature(Upgrade)` never showed an upgrade granted with `extends=` (Explosive Cannon, Improved Defender, Improved Reanimation were all silently missing).
- `calculate_dc` was never rendered anywhere (57 overrides). Since 2026-10-12 the card header shows it as a "Save DC N" chip, so a feature only needs `calculate_dc` for its DC to appear.
- Text that drops "a number of times equal to …" or "(minimum of once)" from the source: common in paraphrased descriptions even where the uses code is right.
- Limited-use features with no use boxes (2026-10-12): about 75 features said "once per Long Rest" or "a number of times equal to ..." but rendered no boxes. All now have them except Boon of Recovery (two separate resources). Multi-benefit features name the limited benefit in the box formula ("Used by Conjured Cauldron.").
- `number_of_uses` missing the minimum of 1 for "equal to your X modifier (minimum of once)": found in Bardic Inspiration, Wrath of the Storm, Embodiment of the Law, Momentary Stasis, Violent Attraction.
- Skill choices described but never granted: Genie's Splendor, Otherworldly Glamour (both now take a `skill` on the level-3 builder).
- PDF hard wraps: the Psion files had one string per PDF line; unwrapped.

**Rendering a build for review:** the snapshot tests can dump every example sheet as HTML:

```
SNAPSHOT_DUMP_DIR=<dir> python -m pytest -m "" tests/test_build_snapshots.py -k <BuildName>
```

After any fix that changes output, regenerate only the affected hashes with `UPDATE_SNAPSHOTS=1 ... -k <BuildName>` and check `git diff tests/snapshots/sheet_hashes.json` lists only the builds you expected.

**Left out on purpose:** features that only grant a fixed proficiency, language, resistance or flat speed (for example Speech of the Woods, the various Bonus Proficiencies, Hex Warrior, Inured to Undeath, Aura of Alacrity, Stonecunning, Lucky). Also left out: the auto-generated monster data in `Combat/Monsters/`, which is a separate concern (for example the 2024 Brown Bear carries a `CHA -2` saving throw).
